turbo · динамический синтез

Харнес, который проектирует сам себя

Вместо ручного Turbo.toml — turbo auto читает cargo metadata, строит граф зависимостей крейтов и раскладывает его в волны параллельного выполнения. Кеш — по содержимому; вывод команды захватывается и воспроизводится при cache hit.

Синтез из cargo metadataНи один крейт не описывается руками — граф зависимостей читается прямо из реального Cargo.toml каждого крейта.
Per-crate fmt-гейтНайденный дог­фудингом баг: общий гейт на весь workspace инвалидировал кеш целиком при любом изменении. Исправлено — гейт per-crate, регрессия закреплена тестом.
sha256-кеш по содержимомуКоманда + байты входных файлов + хеши зависимостей. Тронули один крейт — пересчитан только его конус графа.
Capture + replay stdoutРеальный вывод команды сохраняется в .turbo/output/<hash> и воспроизводится при cache hit — не просто «cached», а настоящий текст cargo test.
Push-based file watchingfs_port::Watcher — реальный notify OS-watcher для RealFs, детерминированный для FakeFs. Пропускает ресканирование, если ничего не изменилось.
