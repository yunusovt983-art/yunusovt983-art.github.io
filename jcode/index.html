01

Видение и язык домена

Что jcode есть по сути, и словарь, которым говорит его код.

jcode — агентный харнесс для написания кода: единый сервер, к которому подключаются множественные TUI / Desktop / mobile-клиенты. Сервер оркестрирует сессии, рой (swarm) параллельных LLM-агентов, инструменты и провайдеров моделей.

Core Domain — то, ради чего продукт существует: параллельная координация роя агентов с DAG-планом, плюс turn-loop одного агента (провайдер ↔ инструменты ↔ контекст).

Session
агрегат диалога — сообщения, git-состояние, компакция. Живёт в jcode-base, не только в DTO-крейте.
Agent
runtime-обёртка вокруг Session: провайдер, turn-loop, очередь soft-interrupt.
VersionedPlan
агрегат роя — единственный источник правды на swarm_id.
TaskGraph
валидированная DAG-форма плана для deep-mode; движок реальных инвариантов.
Provider
порт к внешней LLM-API — trait с ~54 методами, из них 3 обязательны.
Tool
порт возможности агента — 4 метода, контекст сознательно тонкий.
Registry
реестр инструментов и одновременно «толстый» диспетчер с политикой и hooks.
Harness API
внешний, версионируемый язык — CI проверяет полноту покрытия.
Bridge
translate.rs — реальный ACL между внутренним протоколом и harness-api.
Reload
exec() в новый бинарь; через границу переходит только socket path + auth-статус.

04

Доминирующий паттерн

Структура для гейтинга написана — путь исполнения её не вызывает. Семь независимых подтверждений.

ГдеЧто не подключено
SafetySystem::classify()Tier1/Tier2 классификатор — вызывается только в своих тестах, 0 в agent.rs / tool/mod.rs
request_permission.waitполе сохраняется, никогда не читается — обещанная блокировка не существует
MCP × destructive-gateMcpTool::execute зовёт call_tool в обход jcode_command_risk целиком
UsageLog::record()0 продакшн вызывающих — «адаптивный» rate limiter всегда возвращает потолок
active_user_sessionsникогда не инкрементируется — пауза при активном юзере функционально мертва
duplicate_candidates=0hardcoded placeholder — метрика дублей памяти никогда не реальна
promote-before-smoke-testself-dev публикует symlink'и до единственной проверки работоспособности
Наблюдение

Ни одна из семи находок не изолирована — это не баги в отдельных модулях, а повторяющаяся форма решения по всей кодовой базе: тип/структура для контроля пишется и тестируется в изоляции, но реальный вызывающий путь её не подключает.

05

Досье по контекстам

Конденсат из 16 страниц Wiki/Arch в репозитории — полная глубина с file:line там.

Swarm / Plan

01
  • VersionedPlan — единственный источник правды на swarm_id
  • Тест-канарейка подтверждает гонку версий плана как известный баг
  • DAG-движок: owner-check и gate-валидация реально enforced

Session / Server

02
  • Repository snapshot+journal с data-loss guard — образцовый
  • Client lifecycle — без явного state machine, 2400-строчная функция
  • Reload передаёт только socket path + auth-статус, остальное — диск

Provider ACL

03
  • 9 адаптеров, включая реверс-инжинирнутый protobuf для Cursor
  • jcode-schema-dialect — «ACL для ACL» JSON-Schema квирков
  • 3 провайдера ведут tool-loop внутри себя, минуя jcode

Tool / Registry

04
  • Один pub use jcode_base::*; пробивает тонкий порт насквозь
  • tool/communicate.rs — целая встроенная подсистема роя
  • Registry сам стал «толстым» диспетчером с политикой и hooks

Interface / Protocol

05
  • Harness API — CI валит сборку на непротриаженном расхождении
  • Bridge — реальный ACL: firewall, fan-out 1→3, локальные ответы
  • TUI App — 384 поля, 0 reducer'ов во всём крейте

Persistence

06
  • Нет ни одного trait Repository во всём воркспейсе
  • «Согласованные примитивы, несогласованные репозитории»
  • servers.json и config.toml обходят atomic-write

Memory / Embedding

09
  • Гибрид cosine+BM25 (RRF) + listwise LLM-rerank, не top-k
  • «Local embedding off» — compile-time фича, не runtime-переключатель
  • duplicate_candidates захардкожен в 0 — метрика здоровья фиктивна

Ambient Mode

10
  • Concurrency-lock реально работает — «один агент за раз» соблюдён
  • Adaptive rate-limiting исполняется только в юнит-тестах
  • request_permission — совещательный, не блокирует ничего

TUI Render Pipeline

11
  • «>1000fps» — честно про изолированный бенчмарк, экран капнут на 30fps
  • Mermaid-движок — внешняя git-зависимость, не вендорен здесь
  • OKLab-палитра — реальная генерация цвета в рантайме из seed

Desktop2

12
  • Model/App split — кадр как чистая функция, в отличие от TUI
  • Реально потребляет общий render-core IR, не дублирует
  • Ручной hot-reload через dlopen с ABI-fingerprint проверкой

Self-dev / Update

13
  • Тот же reload-путь, что у обычного /reload
  • Publish происходит до smoke-теста — самый серьёзный gap раунда
  • Windows-гейт материально слабее Unix

Safety / Compaction / MCP

14
  • jcode-command-risk — единственный реально живой tier-гейт
  • MCP-инструменты полностью обходят деструктивный гейт
  • git reset --hard / push --force нигде не покрыты

Harness API

16
  • ~30 вариантов против 145 внутренних — курировано намеренно
  • Socket 0600, не 0755 — закрыт реальный security-баг
  • Single-instance flock — упавший bridge не блокирует следующий
06

Самая серьёзная находка

Self-dev — единственная подсистема, где jcode модифицирует собственный исполняемый файл.

Порядок операций перевёрнут

publish_local_current_build_for_source репоинтит current и PATH launcher symlink сразу после лёгкой проверки версии. Единственный тест, который реально доказывает работоспособность бинаря — serve-handshake (smoke_test_server_binary) — вызывается только внутри selfdev reload, и уже после публикации.

Билд, который компилируется и проходит version --json, но крашится на serve, оставляет current/launcher указывающими на сломанный бинарь бессрочно — его подхватит следующий запуск jcode любой сессии на машине, не только текущей.

07

Приоритизированные рекомендации

Свод обоих раундов аудита, по убыванию цены исправления.

  1. Переставить местами publish и smoke-test в self-dev

    smoke-test должен идти до репоинта current/launcher, не после — сейчас единственный работающий гейт срабатывает уже после того, как вред нанесён.

  2. Завести проверку jcode-command-risk на MCP-инструментах

    сейчас единственный путь исполнения, полностью обходящий деструктивный гейт — любой delete/exec-подобный MCP-tool сегодня непроверен.

  3. Дать Tool настоящий capability-scoped порт вместо glob-доступа

    минимум — lint/CI-правило против use crate::X вне allowlist в новых файлах tool/*.rs; закрывает большинство находок в Tool-контексте разом.

  4. Решить судьбу SafetySystem::classify()

    либо реально подключить к диспетчеру инструментов, либо удалить и переписать SAFETY_SYSTEM.md — документация сейчас обещает защиту, которой нет.

  5. Типизировать SwarmMember.status/role на живой сущности

    сейчас String, хотя типизированные enum'ы уже существуют на границе персистентности — дёшево, закрывает целый класс опечаток.

  6. Однострочный фикс: active_user_sessions counter

    нет инкремента/декремента нигде — «пауза при активном пользователе» в ambient-режиме тихо не работает, хотя включена по умолчанию.

  7. Добавить git reset --hard / push --force в jcode-command-risk

    единственный реально enforced гейт не покрывает историю-переписывающие git-команды — расширение allowlist, не новая подсистема.
